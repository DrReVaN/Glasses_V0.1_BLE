# Archivierter OTA-Stand 0.2.0

Diese CPU1-Anwendung stammt exakt aus Commit `f55c08171d64295b727fa613c2b06f6ab733096e` (OTA-Löschkorrektur) und wurde mit Arm GNU Toolchain 13.2.1 gebaut. SHA-256: `0a83823a101f77a41048a1f020ce46e6cd29c149104a56febe2e66f6ce9bfb79`, 35676 Bytes. Der Besitzer hat mit diesem Paket einen erfolgreichen OTA-Durchlauf bestätigt. Die einmalige Binärkopie erhält das konkrete ältere Paket für die neue Versionsauswahl; neue Images werden durch CI gebaut und als Release-Assets veröffentlicht.

Die früheren 0.2.0-Pakete hatten noch keine eindeutige Firmwarekennung. Deshalb wird nur dieser eine ausgewählte Stand als Version 0.2.0 angeboten. Der Rückwechsel verändert den installierten OTA-Löschkorrektur-Bootloader nicht. CPU2, Optionen und Geräteschlüssel sind nicht Bestandteil dieser Dateien.
